# Baro（晴雨表）使用指南

[简体中文](USER_GUIDE.md) | [English](USER_GUIDE.en.md)

**Baro** 是一款专为 macOS（Apple Silicon 优先，支持 macOS 15+ 及 macOS 26/27 Liquid Glass）打造的**纯只读、零入侵**系统状态监控工具。它不包含任何系统清理、进程强杀或风扇控制行为，默认也不联网（仅在「关于」窗口手动检查更新时访问 GitHub），旨在以近乎零感知的功耗陪伴你的 Mac。

---

## 1. 下载、安装与首次打开

1. 前往 [GitHub Releases](https://github.com/seaskyx2/Baro/releases) 下载最新的 `Baro-v*-macOS-arm64.zip`。
2. 双击解压得到 `Baro.app`，将其拖入 **应用程序（`/Applications`）** 文件夹。
3. **首次打开**：
   * 因为本项目为开源个人自签（ad-hoc 签名，未购买 Apple 付费公证），直接双击可能会看到 macOS 的“无法验证开发者”提示。
   * 只需打开「终端（Terminal）」，运行一次以下命令移除下载隔离属性即可正常使用：
     ```bash
     xattr -cr /Applications/Baro.app
     open /Applications/Baro.app
     ```
4. 启动后，Baro **不会在程序坞（Dock）占位置**，它会自动出现在屏幕右上角的**菜单栏**中。

---

## 2. 菜单栏基础操作

Baro 只占用菜单栏中的 **1 个槽位**，避免在刘海屏 Mac 上被遮挡或顺序错乱：

* **左键单击** 或 **全局快捷键（默认 `⌃⌥B`）**：打开 / 收起悬浮仪表盘；点击面板外任意区域或按 `Esc` 键可快速收起（无需辅助功能权限，可在设置更改快捷键组合或关闭）。
* **右键单击**：弹出快捷菜单：
  * **打开晴雨表仪表盘**
  * **复制系统快照**（生成不含 IP、用户名和本地路径的纯文本诊断报告）
  * **偏好设置…**（快捷键 `Command + ,`）
  * **菜单栏模式 ▸**（无需进设置，直接秒切 5 种精工显示风格）
  * **显示晴雨表图标**（一键开关左侧动态负载偏转表盘）
  * **使用指南** / **关于 Baro**
  * **退出 Baro**（快捷键 `Command + Q`）

### 五种菜单栏精工风格
可在右键菜单「菜单栏模式」或「偏好设置 → 菜单栏」（内置 1:1 实时菜单栏光学比例预览）自由切换：

1. **双行精工（默认推荐）**：微分割线隔开的双行精密排布，紧凑贴合零冗余留白，同时呈现 CPU、内存、上下行网速、温度或功耗。
2. **单行胶囊**：以轻盈微描边圆角浅框包裹纯矢量微缩芯片/内存/闪电符号与等宽读数，适合外接大屏舒展扫视。
3. **脉搏微图**：左侧为带柔和阴影面积的平滑 CPU 波形微视窗 + 百分比，右侧搭配 Apple Watch 风格的精密内存圆环微表盘。
4. **精工双柱**：100% 原生单色光学反色的双槽立式液位表（高负载自动点亮预警色），极致节省刘海屏空间。
5. **灵动圆环**：双层同心宝石光晕呼吸灯——平稳时静谧克制，当系统处于高压态时自动在圆环旁浮现占用最高 App 的图标。

## 3. 仪表盘模块与隐藏交互技巧

左键点开仪表盘后，你将看到一屏紧凑的 Bento 便当盒界面：

### 隐藏交互技巧
1. **点击卡片原地展开二级详情**：
   * **CPU 卡片**：点击展开 **全核心实时柱状图抽屉**（区分紫色 `P` 性能核与青色 `E` 能效核）以及 1m / 5m Load Average。
   * **统一内存卡片**：点击展开完整明细（App 内存、联动内存、已压缩、已缓存文件、剩余可用）。
   * **功耗 & GPU 卡片**：点击展开 **只读热敏与风扇传感器清单**（各芯片区域温度与风扇当前/最大 RPM）。
   * **磁盘存储卡片**：点击展开 **NVMe S.M.A.R.T. 健康只读详情**（SSD 剩余寿命 %、累计写入 TBW、累计读取、通电时长与 SSD 温度）以及其余挂载卷的剩余容量。
  * **一键复制脱敏快照**：点击仪表盘右上角的复制图标，即可复制脱敏后的系统状态纯文本。
  * **电源与防休眠提示**：若有应用正在阻止 Mac 休眠或息屏，电源卡片与顶部健康摘要会自动点名提醒。
   * *再次点击任意已展开的卡片即可平滑收起。*
2. **折线图鼠标悬停读数（Hover Inspect）**：
   * 把鼠标轻轻滑过 CPU、内存、功耗或网络卡片里的任意一条折线图，会出现一条细游标线和气泡，实时显示该历史时间点的精准读数。

### 各卡片指标说明
* **顶部人话健康摘要**：用直观语言概括系统当前状态（例如 `系统平静 · 零交换压力`、`高负载 · Xcode 占用 64% CPU`、`温度偏高 · SoC 94°C`）。
* **CPU**：总负载、P 核与 E 核分簇平均负载、主芯片温度与 1 分钟系统平均负载。
* **统一内存**：采用与 macOS「活动监视器」一致的已用内存口径（App + 联动 + 压缩），下方三段彩条分别对应 App（蓝）、联动（橙）、压缩（紫），并实时显示 `Swap` 用量与系统内存压力等级（正常 / 偏高 / 紧张）。
* **功耗 & GPU**：
  * 免 `sudo` 读取 Apple Silicon GPU 利用率与能耗，并在硬件支持时读取整机实时供电瓦数与分项功耗（CPU / GPU / ANE / DRAM）。
* **网络吞吐**：仅统计物理活跃网卡的实时下载（`↓`）与上传（`↑`）速度、主网卡名（如 `en1`）、局域网 IP 及本次开机后的会话累计流量。
* **磁盘存储**：展示主卷已用比例、剩余容量与物理块设备实时读/写速率。
* **电源与电池（双形态自适应）**：
  * **MacBook（有内置电池）**：环形电量仪表、实时充/放电瓦数、电池健康度、循环次数、电池温度、适配器瓦数、预计剩余续航，以及已连接的苹果 HID 外设电量。
  * **台式机（Mac mini / Mac Studio / iMac）**：自动切换为交流供电视图，展示整机实测供电功率（硬件支持时）以及苹果蓝牙键鼠/触控板（`IOKit HID` 免弹窗读取）电量；在设置中开启「在台式机上预览笔记本电池卡片」即可体验完整的笔记本电池界面。
* **资源占用排行（按 App 归并）**：
  * 仅在面板打开时瞬时采集；自动把 `Chrome Helper`、`Renderer` 等零散子进程合并回父级 `.app`（显示真实 App 图标与 `×进程数` 角标），支持 `[CPU | 内存]` 一键切换查看。

## 4. 偏好设置说明

点击仪表盘右上角的齿轮 `⚙` 或右键状态栏图标选「偏好设置…」即可打开：

* **常规**：
  * **登录时自动启动 Baro**：通过系统原生 `SMAppService` 注册（请确保已把 `Baro.app` 放入 `/Applications`）。
  * **低电量模式下自动放慢采样频率**：在笔记本开启省电模式时自动加倍刷新间隔。
  * **冷热分层采样频率**：分别调整「面板收起（冷态）」与「面板展开（热态）」的刷新间隔。
* **菜单栏**：内置实时状态栏比例预览条，可一键切换 5 种精工显示风格、开关动态晴雨表表盘图标，并自由勾选要在菜单栏常驻显示的指标（建议选 2–3 项以保持清爽）。
* **模块与提醒**：
  * 开关主面板中的任意一张卡片；
  * 开关「在台式机上预览笔记本电池卡片」；
  * **可选只读通知提醒（默认全部关闭）**：按需开启高温阈值提醒（75°C–105°C 可调）、内存压力紧张提醒或笔记本低电量（≤ 15%）提醒（内置 10 分钟防刷屏冷却）。

## 5. 零残留卸载

Baro 无任何后台守护进程（`LaunchDaemon`）、无独立 Helper、无系统插件与磁盘历史库。需要卸载时：

1. 右键菜单栏 Baro 图标选择「退出 Baro」；
2. 将 `/Applications/Baro.app` 拖入废纸篓即可完全清除（若曾在设置开启登录项，系统会自动移除）。

## 6. 常见问题（FAQ）

* **Q：为什么不显示 Wi-Fi 名称（SSID）或 AirPods 电量？**
  * A：新版 macOS 读取 Wi-Fi SSID 会强制触发“定位权限”弹窗，读取 AirPods 等第三方蓝牙设备电量会触发“蓝牙权限”弹窗。为了彻底贯彻“零隐私弹窗、零打扰”，Baro 故意放弃了这两项，仅通过内核 `IOKit HID` 免弹窗读取苹果官方键鼠/触控板电量。
* **Q：为什么有些 M4 设备上看不到 CPU/ANE 单项瓦数，只看到整机功耗与 GPU 功耗？**
  * A：在较新的 macOS 与 M4 系列芯片的非 root 环境下，系统对 `IOReport` 部分能源通道做了收紧；Baro 会自动回退读取 `PowerTelemetryData` 与只读 `AppleSMC` 提供的整机实测供电功率，保证总功率准确可用且无需任何提权。
* **Q：电脑息屏或合盖睡眠时它还在跑吗？**
  * A：不会。Baro 监听系统息屏与休眠通知，睡眠期间自动暂停所有采样定时器，绝不阻止 Mac 深度休眠；唤醒时自动重置差分基线，避免网络或 CPU 曲线出现瞬时假尖峰。
